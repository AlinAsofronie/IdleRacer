## Milestone 0.1 — Core Vertical Slice

Goal:

Prove that watching an auto race while generating and upgrading equipment is fun.

Scope:

- one basic race screen,
- two cars,
- simple straight track,
- mathematical race simulation,
- Acceleration,
- Top Speed,
- Normal 1-1 to 1-10,
- Gold,
- Wheels,
- manual Item Creator,
- eight equipment slots,
- simple rarities,
- local save,
- Auto Build unlock after Normal 1-10.

Not included:

- PvP
- Prestige
- dungeons
- companions
- trainers
- skills
- cloud backend
- refinement
- advanced tracks

Status:

- 0.1A Headless race simulator — COMPLETED
- 0.1B Visual race prototype — COMPLETED
- 0.1C First playable incremental loop (Normal 1-1..1-10, Gold, Wheels, Item Creator,
  8 equipment slots, rarities, Item Creator levels, Auto Build unlock) — COMPLETED
- 0.1D Gold slot upgrades + local save (V1) + offline-duration foundation — COMPLETED
  (offline rewards deferred to a later milestone)
- 0.2A Proper mobile UI shell + tab navigation — COMPLETED
  (Garage / Build / Upgrades / Race / More; persistent race + resource bar; presentation-only tabs)
- 0.2B Playtest-ready mobile UI/UX overhaul — COMPLETED
  (TMP, UiTheme, compact numbers, race presentation FX, redesigned tabs/nav for portrait playtests)
